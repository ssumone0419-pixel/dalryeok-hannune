# 달력한눈에 — 최종 정리 버전 v21

기준: v20. 화면·날짜 계산·기념일 저장·공휴일 API 기능을 유지하며 불필요한 과거 배포 문서와 미사용 스타일 파일을 정리하고 양력·음력 변환 결과의 두 링크 스타일을 통일했습니다.

## 배포
1. 이 폴더의 내용물을 GitHub 저장소 루트에 반영합니다.
2. 기존 저장소에 있는 Google Search Console 인증 파일 `google73190272abadf991.html`은 **삭제하지 마세요**. 이 배포 ZIP에는 인증 파일이 없습니다.
3. Cloudflare Pages의 `HOLIDAY_API_KEY` 환경변수를 유지합니다.
4. Cloudflare Pages 배포가 Success인지 확인한 뒤 주요 페이지를 테스트합니다.

## 점검
- 양력·음력 변환 결과에서 '달력에서 보기', '디데이 보기'가 같은 버튼 스타일인지 확인
- 날짜를 변환한 후 각 버튼이 해당 양력 날짜로 이동하는지 확인
- 달력에 기념일을 저장하고 디데이 페이지에서 같은 브라우저로 연동되는지 확인
- 공휴일 API와 월별 달력 이동이 작동하는지 확인
- 모바일 너비에서 버튼·메뉴가 겹치지 않는지 확인

## 유의사항
- 기념일은 브라우저 localStorage에 저장됩니다. 다른 브라우저/기기와 동기화되지 않습니다.
- 음양력 변환은 기존에 포함된 한국천문연구원 기반 날짜 데이터(`assets/lunar-data.js`)를 그대로 사용합니다. **더미 데이터가 아니므로 삭제하지 않았습니다.**
- `functions/api/holidays.js`는 공휴일 서버 기능으로 삭제하면 안 됩니다.
- JavaScript 문법 및 정적 연결 검사는 수행했지만, 실제 모바일 브라우저와 실시간 공휴일 API를 종단 간 테스트하지는 않았습니다.


## v22 모바일 개선
- 5개 메뉴를 모바일에서 3+2 형태로 정렬하고 터치 영역 확보
- 디데이·공휴일·달력·나이 계산기의 모바일 여백과 글자 크기 조정
- 작은 화면에서 입력창 확대 및 가로 넘침 방지
- `assets/mobile-polish.css`를 마지막에 불러오므로 이전 CSS를 안전하게 보완
- 계산 로직과 API 함수는 변경하지 않음


## v23 영업일 계산
- 디데이 페이지에서 날짜 차이 탭을 영업일 계산으로 변경했습니다. 디데이 결과에 달력 일수 차이는 유지합니다.
- 영업일 계산은 `/api/holidays?year=YYYY`를 통해 공식 공휴일을 조회합니다. 시작일 제외, 종료일 포함 기준이며 토·일요일 및 조회된 공휴일을 제외합니다.
- N영업일 후 날짜 계산도 지원합니다(1~1000일). 공휴일 API 오류 시 부정확한 결과를 표시하지 않습니다.
- 최대 6개 연도, 1900~2050년 범위를 지원합니다. 기관별 자체 휴무일은 포함하지 않습니다.
